The source CSV files and SQLite database are local build inputs and outputs;
they are not committed to this repository. The source manifest records the
eight selected CSV files and their checksums. Detailed geolocation is excluded.

The import preserves every decoded source field. It changes the storage
format to SQLite and adds an audit table and a row-count view. Any shared
source data or data-derived database remains subject to the dataset's licence,
including attribution, NonCommercial and ShareAlike conditions.

Part 8 includes a reduced, data-derived JavaScript export in dashboard/data.js
and static data previews. These remain subject to the same dataset licence.
The export omits raw identifiers and free-text reviews, and uses stable integer
indexes to group customers and order/category rows for local browser filtering.
