## File-size handling

GitHub browser uploads are limited to 25 MiB per file. Larger files up to 100 MiB can be added with Git; files above 100 MiB require Git LFS or an appropriate release/download approach. Keep the dashboard screenshots available regardless of how the editable file is shared.

- https://docs.github.com/en/repositories/working-with-files/managing-files/adding-a-file-to-a-repository
